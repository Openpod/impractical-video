# README media

Concept: show the real workspace, with room for the work itself.

White background, charcoal text, Impractical red `#ed1d24`, the app's native
sans-serif typography. Straight-on browser captures at 1440 × 960; no device
frames, UI reconstruction, AI generation, image editing, or manual compositing.
The SVG is an exact export of `app/impractical-logo.tsx`, with a red ticket,
white uppercase I, and white perforations.

Captured on 2026-09-23 from an isolated local production build. The canvas is
a sample project made from Impractical's public Explore reference images:
Momo Bean, Willa Thistle, Nonna Rosa, Verdant Overgrowth, Storybook Watercolor,
and Claymation Clay. These references are published in the catalog by Simar
Kohli. Explore shows the public catalog as displayed by the app. The onboarding
capture shows the generation choices without entering credentials or purchasing
anything. No private projects or API keys are shown.

The PNGs are raw Playwright screenshots. The logo is a source SVG export.
